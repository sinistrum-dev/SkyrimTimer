# SkyrimTimer

A free, unofficial, non-commercial Skyrim fan-made Pomodoro productivity app.

SkyrimTimer combines a Pomodoro timer with Skyrim-inspired locations, progression, perks, weather effects, and ambient visuals to make focused work sessions more immersive.

## Features

- Pomodoro work and break timer
- Work-time progression and levels
- Perk system
- Skyrim-inspired locations and travel
- Dynamic weather effects including rain, snow, and smoke
- Background and ambient effects
- Local save data
- Windows and macOS builds
